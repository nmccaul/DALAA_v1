The problem

Students adapted to AI. Most assignments haven't.

Students

Use AI for coursework every day, mostly with no structure or guidance on how to use it well.

Assignments

Still grade a finished product, an essay or an answer, which AI can now produce in seconds.

Teachers

Can no longer tell from the work what a student actually understands.

Students changed how they work almost overnight. Most assignments still measure a finished product, and a polished product no longer proves understanding, so teachers lose their view of what students know. If you want a number here, add a student AI-use figure from a source we can cite.
